Movie Rental Analytics

Project Overview

Movie Rental Analytics is a data analysis project based on the Sakila DVD Rental Store Database. The project focuses on understanding customer behaviour, film rental trends, revenue generation, staff performance and store operations.

Project Objectives

Analyse customer rental behaviour.

Identify popular film categories.

Understand revenue and monthly rental trends.

Compare store and staff performance.

Identify high-value customers.

Generate useful business insights.

Tools & Technologies

SQL – Data querying and analysis

Microsoft Excel – Data organization and analysis

Power BI – Dashboard and data visualization

Key Analysis Areas

Customer Behaviour Analysis

Film Category Analysis

Rental Rate Analysis

Revenue Analysis

Staff Performance

Store Performance

Inventory Analysis

Rental Time Trends

Key Findings

Total Revenue: 67.41K

Total Rentals: 16.044K

Total Customers: 599

Total Films: 1K

Tuesday was the busiest rental day.

3 PM was the busiest rental hour.

Customer rental patterns and category preferences varied across stores.

Conclusion

This project helped analyse movie rental business data and identify useful patterns related to customers, films, revenue and store operations. The findings can support better business decisions and inventory planning.
